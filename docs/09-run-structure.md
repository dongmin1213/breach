# 09 · 런 구조 — 30분 작전

한 판을 30분으로 키우면서 무엇을 바꾸고 **무엇은 절대 안 바꾸는지** 적는다.
수치의 단일 원본은 여전히 [`assets/balance.json`](../assets/balance.json) 이다.

---

## 왜 바꾸는가

기존 구조는 **5~7 계층 · 결정 5.7회 · 한 판 3분**이었다. 두 가지가 무너져 있었다.

**① 얻는 축이 없다.** 상태 변수가 전부 비용이다 — 탐지도는 오르고, 저항은 쌓이고,
경계는 오르고, 손패는 줄어든다. 한 판이 **순수 소모전**이라 시작이 가장 강하고
끝으로 갈수록 약해진다.

그래서 [`06-findings §2`](06-findings.md) 의 콤보 4종이 전부 실패한 것이 우연이 아니다.
**쌓아서 터뜨릴 게 없으면** 시너지는 원리적으로 안 생긴다. 플레이 실력 폭이
6.9%p 인 것도 같은 뿌리다 — 매 계층이 "가진 것 중 덜 나쁜 것 고르기"다.

**② 픽션과 규모가 안 맞는다.** "국방부 내부망 전체"를 카드 6장으로 뚫는다.
침투는 점점 깊이 들어가는 이야기인데 게임은 마모되기만 한다.

## 30분이 요구하는 것 — 산수 먼저

⚠️ 처음엔 "채점 계층 38"로 잡았다가 틀렸다. **카드 수급이 안 맞는다** —
38계층이면 카드를 38장 내야 하는데 덱 12 + 보상으로는 못 채운다.
30분은 카드를 내는 결정만으로 채우는 게 아니라 **보상·경로·정찰이 함께** 채운다.

```
30분 = 1800초

채점 계층 24 × 25초 = 600     ← 카드를 내는 결정
보상 선택 12 × 20초 = 240
경로 선택 10 × 15초 = 150
정찰·이벤트 6 × 20초 = 120
                     ─────
                      1110초 + 읽는 시간 ≈ 25~30분
```

**채점 계층 24.** 덱 12 + 보상 ~12 = 24장이라 수급이 맞는다.
기존 5~7 계층의 네 배이고, 결정 총량은 5.7 → **52회**다.

따라서 무너지는 전제가 셋이다.

| 기존 전제 | 24계층에서 |
|---|---|
| 손패 = 계층+4, 리필 없음 | 손패 11장으로 24계층 불가 → 국면 재보급 |
| 덱 12장 고정 | 보상으로 24장까지 성장 |
| 탐지도 100 / 6계층 ≈ 16/계층 | 100 / 24 ≈ **4.2/계층** — 기존 밸런스 전면 재조정 |

## 구조

```
작전 (한 판 · 30분)
├─ 국면 1  침투    계층 8  → 관문
├─ 국면 2  확산    계층 8  → 관문
└─ 국면 3  코어    계층 8  → 최종 코어
```

### 국면 단위 재보급 — 픽션 기둥을 지키는 방법

[`01-overview`](01-overview.md) 의 네 기둥 중 하나가 **「쓴 익스플로잇은 패치된다」**
= 손패 리필 없음이다. 이걸 깨면 주제와 규칙의 자연스러움이 무너진다.

그래서 **국면 안에서는 그대로 소모**하고, **국면 사이에만 재보급**한다.
한 작전 안의 국면이 바뀌면 다른 도구를 챙겨 들어간다 — 픽션도 유지되고
24계층도 감당된다.

덱은 보상으로 **12 → 24장**까지 자란다. 국면마다 남은 덱에서 손패를 뽑으므로
「보상으로 덱을 불리는 것」이 곧 「다음 국면을 버틸 연료」가 된다.

### 탐지도는 이월 유지

[`02-rules §1`](02-rules.md) 이 "TRACE 가 계층마다 초기화되지 않는 것이 이 게임의 척추"
라고 못 박았다. 국면 사이에도 **초기화하지 않는다.**

국면 3에 들어갈 땐 이미 70 근처다. 카드 한 장이 치명적이 된다 —
**긴장 곡선이 수치를 키우지 않고 경제에서 나온다.** 이게 30분을 지루하지 않게 만드는 축이다.

## 새로 들어가는 것 일곱

### ① 런 중 덱 성장 — 없는 축을 만든다

계층을 뚫을 때마다 보상을 고른다.

```
새 도구 3장 중 1장을 덱에 추가
보유 도구 1장 강화
흔적 −N
```

「쓴 도구는 사라진다」와 맞물려 **소모 vs 보충**의 긴장이 처음 생긴다.
이것이 나머지 여섯의 토대다 — 얻는 축이 있어야 나머지가 얹힌다.

⚠️ **강화는 스탯을 올리는 게 아니다.** 요구치가 문턱이라 초과분은 여유(0.70)로만 남아
거의 무가치하다 ([`06 §1①`](06-findings.md)). 강화는 **소음을 낮추거나 효과를 붙이는**
쪽이어야 한다.

### ② 침투 경로 — 런에 서사를 준다

다음 계층을 2~3 갈래에서 고른다. 갈래마다 유형·난이도·보상이 다르다.
「조용히 쉬운 길」 vs 「시끄럽지만 크게 버는 길」이 매 판을 다르게 만든다.

### ③ 계층 유형 확장 — 반복감 제거

기존 암호·망·물리는 **요구 스탯과 소음 계수 숫자만 다르다.** 규칙이 같아서
38번이 같은 동작의 반복이 된다. 규칙이 다른 계층을 추가한다.

| 계층 | 규칙 |
|---|---|
| 인증 | 권한 게이지 없이는 못 뚫는다 (스탯 무의미) |
| 감시 | 카드를 두 장 내야 한다 |
| 격리 | 장비가 봉인된다 |
| 허니팟 | 뚫으면 오히려 흔적 급증 — 우회가 정답일 수 있다 |
| 시간 | 매 턴 여유가 깎인다 |

### ④ 방어자 인격화

지금 저항·경계·능동대응은 **보이지 않는 수식**이다. 이름·얼굴·대사를 붙이면
"시스템이 날 읽고 있다"가 읽히기 시작한다.

⚠️ **예고 규칙([`02 §6`](02-rules.md))은 절대 안 깬다.** 인격화는 연출이지 규칙 변경이 아니다.

### ⑤ 부분 이탈

코어 전에 빠져나올 수 있다. 깊이 갈수록 보상이 크지만 흔적이 누적된다.
「지금 빠질까 한 층 더 갈까」가 매 계층 생긴다.

### ⑥ 연속 작전(챕터)

표적 하나 = 3~5 런. 흔적·장비·덱이 이월된다.
국방부 내부망이 한 판이 아니라 **작전**이 된다.

## 실패와 메타 — 확정된 결정

```
실패      완전 초기화 (30분 전부 손실)
메타      해금 + 영구 강화
```

완전 초기화는 매 결정의 무게를 최대로 만든다. 30분 손실을 감당하려면 둘이 필요하다:

- **실패가 배울 수 있어야 한다** — 결정론이라 `완전히 같은 판 다시`가 되고,
  예고 규칙이 "예고 없는 패배"를 금지한다. 이 둘이 이 선택의 전제다.
- **실패해도 뭔가 남아야 한다** — 그게 영구 강화다.

### ⚠️ 영구 강화는 문턱을 건드리면 안 된다

[`01-overview`](01-overview.md) 의 측정: **등급 총합이 2점(1.7%)만 달라도 상위 덱이
74.6%로 압승**한다. 문턱 시스템이라 작은 접근점수 차가 통과/미달을 갈라 증폭된다.

영구 강화는 매출이 아니라 플레이로 얻으므로 가챠와 다르지만, **그 측정은 그대로 유효하다.**
그래서 **선택의 폭을 넓히는 축으로만** 설계한다.

| 넣는다 (접근점수에 직접 안 닿음) | 안 넣는다 (문턱을 흔든다) |
|---|---|
| 시작 장비 +1 | 시작 여유 +N |
| 보상 후보 3장 → 4장 | 최대 탐지도 100 → 120 |
| 시작 덱 크기 +N | 모든 카드 스탯 +N |
| 재보급 시 교체권 | 요구치 −N% |

오른쪽으로 가면 `M8′`(상위 덱 다양성)과 `M1`(성공률)이 무너지고,
결국 "업그레이드 다 찍으면 쉬워지는" 게임이 된다.


## 작업 순서

각 항목마다 [`04 §파레토 검사`](04-balance.md) 를 통과시킨다.
**한 번에 다 넣으면 어느 것이 지표를 깼는지 알 수 없다** —
카드 확충에서 이미 그렇게 실패했다 ([`06 §7`](06-findings.md)).

```
1. 측정 도구 정합성      (선행 — 새 밸런스를 이 자들로 잰다)
2. 이 문서
3. JS 기준 엔진 개편      런 구조 · 국면 · 보상 · 경로
4. 감사 추가 + 파레토 검사
5. Dart 포팅 + 골든 재생성
6. UI 재구성 + 플레이 테스트
```
