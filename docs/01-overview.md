# 01 · 개요 — 무슨 게임이고 왜 이렇게 설계했는가

## 한 줄

> **같은 표적을, 누가 더 영리하게, 더 조용히 뚫는가.**

싱글플레이 유료 카드 로그라이크. 세로 모바일. 가챠 없음.

당신은 해커다. 여러 겹으로 보호된 시스템을 계층 하나씩 뚫고 코어까지 들어간다.
계층마다 **필요 침투도**가 있고, 도구를 쓸 때마다 **탐지도**가 오른다. 탐지도 100이면 잡힌다.

---

## 왜 이 게임이 존재하는가

이 프로젝트에는 폐기된 전작이 있다 — 카트 레이싱 카드배틀.
400개 관점 감사를 통과하고도 접었다. 사유는 밸런스가 아니라 **구조**였다.

```
카드에 비용이 없었다.
  → 강한 카드를 안 낼 이유가 없다
  → 카드 차별화 수단이 "스탯 배분" 하나뿐
  → 측정: 스탯 배분 6종의 성능 차이 = 2%p
  → 카드를 200장 만들어도 실질 6종
```

BREACH 는 그 하나를 고치려고 만들었다. **탐지도(TRACE)가 비용 축이다.**

같은 질문을 다시 던져 측정한 결과:

| 질문 | 전작 | BREACH |
|---|---|---|
| 스탯 배분 6종의 성능 스프레드 | 2.0%p | **23.0%p** |
| 두 축이 서로 다른 카드를 선호하는가 | (축이 하나) | 선택 일치율 **28.7%** |
| 비용 축을 제거하면 | (없음) | 53% → **94.5%** |
| 성능 축을 제거하면 | 100% | 53% → **99.9%** |

두 축 모두 실제로 물린다. 이게 존재 근거다.

---

## 왜 침투/해킹인가

주제는 취향이 아니라 **규칙의 자연스러움**으로 골랐다.
레이싱에서는 억지 설명이 필요했던 규칙 넷이, 침투에서는 설명이 필요 없다.

| 규칙 | 레이싱에서 | 침투에서 |
|---|---|---|
| 손패 리필 없음 | 왜 카드가 안 오지? | **쓴 익스플로잇은 패치된다** |
| 적응형 방어 | 라이벌이 왜 내 패턴을 읽지? | **보안 시스템이 로그를 학습한다** |
| 비용(소음) | 억지로 넣어야 함 | **탐지도** |
| 같은 시드 경쟁 | 같은 트랙? 어색 | **오늘의 표적** |

---

## 이 게임의 정체 — 콤보 덱빌더가 아니다

측정으로 확인한 구조적 사실이 하나 있다.

```
기초 습득 이후 플레이 실력의 폭   6.9%p
표적별 전용 덱의 홈 어드밴티지   13.6%p
```

**덱 선택이 플레이 실력보다 두 배 중요하다.**
그리고 카드 콤보 시너지는 구조적으로 약하다 ([06-findings](06-findings.md) 참조).

따라서 BREACH 는 **툴킷 선택 게임**이다 (Into the Breach 계열).
깊이를 더하려면 카드 콤보가 아니라 **표적 원형과 카드 종류**를 늘려야 한다.

---

## 상업 형태

```
유료 단품 (Slay the Spire 모델). 가챠·확률형 없음.
플랫폼: 세로 모바일 우선 → 웹 → 데스크톱
```

가챠를 뺀 이유는 윤리가 아니라 설계 정합성이다.
가챠가 있으면 **툴 강도 격차가 곧 매출**이 되므로,
[04-balance](04-balance.md) 의 "등급 총합은 완전히 동일" 같은 평탄화 설계를 유지할 수 없다.
실제로 등급별 총합이 **2점(1.7%)만 달라도 상위 덱이 74.6%로 압승**한다.

플레이로만 쌓이는 재화의 **해금**은 다르다. 그건 수평 확장이라 밸런스를 안 깬다.
