# 05 · 검증 — 절차와 규약

```
tools/verify.sh          전 구간 (아래 5단계)
node sim/runAll.mjs      감사 221개
dart test                Dart 엔진 18개
dart test -p chrome test/prng_web_test.dart   웹 정수 의미론
```

---

## 왜 이 문서가 먼저인가

전작에서 400개 관점 감사를 돌려 **엔진 버그 7건 · 측정 오류 6건 · 구조 결함 2건**을 찾았다.
가장 값진 산출물은 밸런스 수치가 아니라 **어떻게 재야 하는가**였다.

그리고 BREACH 에서도 **같은 유형의 측정 오류가 14건 반복됐다.**
§2 의 규약을 직접 써놓고 네 번 위반했다. 그래서 규약을 먼저 못 박는다.

## 2. 측정 조건 규약 — 가장 많이 어긴 것

> **모든 지표는 현실적 플레이 조건에서 잰다.**

| 금지 | 왜 | 대신 |
|---|---|---|
| 단일 프리셋으로 주 지표 측정 | 프리셋 특이성이 섞인다 (실측 Δ11.6%p) | **무작위 덱** (`std()`) |
| "그것만 8장" 덱으로 콘텐츠 가치 측정 | 저항 포화로 천장(99%)/바닥(0.3%)에 붙는다 | **한계 기여** (`marginal()`) |
| 무작위 표본 **한 쌍**으로 분포 대표 | 그 한 쌍의 특이성을 잰다 | 40쌍 이상의 분포 |
| 성공 판만 평균낸 점수 | 드물게 성공하고 크게 먹는 쪽이 1위로 보인다 | **`expScore`** (실패=0 포함) |
| 효과를 **작동 못 하는 조건**에서 측정 | morph 를 균형형에서 재면 0 | 효과별 전용 조건 |
| 소음 가격을 카드 단위로만 검증 | 대조 덱이 흔적을 흡수 (6.9% vs 31.1%) | **덱 단위** |

## 3. 측정 도구 반증

**봇 정책이 틀리면 그 봇으로 잰 모든 수치가 편향된다.**

정기적으로 **대안 정책으로 현행을 이기려 시도한다.** 이기면 현행이 틀린 것이고,
그 정책으로 잰 지표를 전부 다시 재야 한다. 실제로 세 번 잡았다:

- 전작: 아이템 정책이 단순 정책에 62.5% 패배
- BREACH: 장비 정책이 단순 정책에 27.3% 패배
- BREACH: 계획 봇이 근시안 봇에 52.8% vs 53.7% 로 패배

**봇 사다리의 모든 봇은 같은 목적함수를 최적화해야 한다.** 탐색 깊이만 달리한다.
목적함수가 다르면 "더 똑똑한 봇"이라는 말 자체가 성립하지 않는다.

## 4. 통계 규약

| 항목 | 규약 |
|---|---|
| 표본 | 주 지표 n≥8,000. 2pp 차이 검출에는 9,800판 필요 |
| 시드 | 훈련(1,000,000~) / 검증(7,000,000~) **완전 분리** |
| 다중 비교 | 221개 검사 중 10건 내외는 우연히 실패한다. 경계 ±2pp 이탈은 노이즈 |
| 재현 | 모든 측정 시드 고정 |
| RNG | mulberry32 고정. `Math.random`·시각 의존 전면 금지 |

⚠️ **N개 중 최대값을 고르는 것은 노이즈를 고르는 것이기도 하다.**
챔피언 덱을 검증 시드로 뽑고 같은 시드로 평가하면 홈 어드밴티지가 통째로 선택 편향일 수 있다.
반드시 훈련 시드로 뽑고 검증 시드로 평가한다.

## 5. 포팅 검증 — 골든 픽스처

JS 엔진(`sim/core/`)이 기준이고 Dart 엔진(`lib/shared/engine/`)이 그것을 재현해야 한다.

```
node sim/golden.mjs   →  test/golden.json
  PRNG 7시드 × 12회 + 2000회 누적합
  카드 파생 30
  표적 생성 300
  덱 추첨 60
  전체 플레이 로그 400런 (이벤트 4,644개)

dart test
  소수점 6자리까지 대조
```

**이 테스트가 통과해야만 감사 221개가 앱을 설명한다.**
실패하면 밸런스 수치도, 데일리 모드도, 서버 검증도 전부 의미를 잃는다.

### 웹 검증이 따로 필요한 이유

Dart 네이티브 int 는 64비트지만 **웹(dart2js)에서는 double** 이라
2^53 을 넘는 중간값이 조용히 뭉개진다. VM 테스트만으로는 못 잡는다.

```
dart test -p chrome test/prng_web_test.dart
```
