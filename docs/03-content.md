# 03 · 콘텐츠 — 카드 · 표적 · 효과

정의의 단일 원본은 [`assets/balance.json`](../assets/balance.json),
표시 이름은 [`assets/l10n/`](../assets/l10n/) 이다.
**카드를 추가하려면 JSON 두 줄이면 되고 코드는 안 건드린다.**

---

## 1. 카드를 구성하는 다섯 축

전작에는 축이 사실상 **하나**(스탯 배분)뿐이라 카드 200장을 만들어도 실질 6종이었다.

| 축 | 값 | 무엇을 만드는가 |
|---|---|---|
| **스탯** | DEC / EVA / INF 배분 | 어느 계층에 강한가 |
| **소음** | 0 ~ 4 | **비용.** 이 축이 나머지 넷을 살린다 |
| **유형** | 정공 / 우회 / 강습 | 방어 저항의 대상 |
| **권한** | +2 / +1 / 0 / 소비 | 턴을 가로지르는 라인 |
| **효과** | 7종 | 규칙 자체를 비트는 예외 |

소음이 없으면 나머지 축이 전부 **덧셈 보너스**로 흡수되어 한 줄의 파워 수치가 된다.
소음이 있어야 각 축이 "이 비용을 낼 가치가 있는가"라는 별개의 질문을 갖는다.

## 2. 소음이 스탯 예산을 산다

소음 1점 = 스탯 예산 12점.

| 소음 | 추가 예산 | 정예 총합 |
|---|---|---|
| 0 | +0 | 116 |
| 2 | +24 | 140 |
| 4 | +48 | 164 |

이게 없으면 고소음 카드는 그냥 나쁜 카드다 (초판: 소음 2 이상 성공률 1.3%, 강습 유형 점유율 5.5%).

⚠️ **가격은 반드시 덱 단위로 검증한다.** 카드 하나를 대조 덱에 넣어 재면 대조 덱이
흔적을 흡수해 과소평가된다 — 카드 단위 스프레드 6.9% vs 덱 단위 31.1%.

## 3. 유형 세 종

| 유형 | 성격 | 저항 1당 감소 |
|---|---|---|
| **정공** | 정면 돌파 | 13% |
| **우회** | 안정적 | 7% |
| **강습** | 최고 화력·최고 소음 | **18%** |

## 4. 효과 일곱 종

| 효과 | 하는 일 | 대가 |
|---|---|---|
| **은폐** | 이 카드의 소음 0 | 접근 −25% |
| **소거** | TRACE −8 | — |
| **적응** | 계층 주스탯 대신 **자신의 최고 스탯**을 주스탯으로 | 접근 −10% |
| **과부하** | 접근 +35% | 소음 ×2 |
| **백도어** | **요구치 판정을 건너뛴다** (미달 페널티 0) | TRACE +26 · 접근 −50% |
| **정찰** | 여유 +10 선지급 | 접근 −15% |
| **폭주** | 경계 단계당 접근 +30% | 기본 배수 0.72 |

효과는 **덧셈 보너스가 아니라 규칙의 예외**여야 덱 구성의 축이 된다.

효과 설계에서 여러 번 실패했고 그 기록은 [06-findings](06-findings.md) 에 있다.
새 효과를 만들기 전에 반드시 읽을 것.

## 5. 등급

```
기본 · 정예 · 전설  — 총합 예산 116 (완전 동일)
                     개별 상한만 84 / 86 / 88
```

**총합은 절대 차등하지 않는다.** 2점(1.7%) 차이로 상위 덱이 74.6% 압승한다
(근거는 [04-balance](04-balance.md)). 남은 차이는 "한 스탯에 얼마나 몰 수 있는가"뿐이다.

## 6. 카드 풀 — 2026-08-03 기준 30종

실제 개수는 `assets/balance.json` 의 `cards` 배열이 원본이다.

정의는 `assets/balance.json` 의 `cards` 배열이 원본이다. 스탯은 예산 규칙에서 자동 파생된다.

**30종은 적다.** 소거는 1장, 과부하는 1장뿐이라 그 카드를 못 뽑으면 그 전략이 사라진다.
목표는 60종 안팎 (표적 전용 6×6 + 범용 24).

멈추는 시점은 감으로 정하지 않는다:
```
카드를 추가하다가
  상위 8덱의 카드 겹침(현재 37.4%)이 더 안 내려가고
  표적별 홈 어드밴티지(현재 13.6%p)가 더 안 오르면
  그때가 충분한 지점
```

## 7. 표적 원형 — 현재 6종

| 표적 | 계층 분포 | 그 밖의 레버 |
|---|---|---|
| 통신사 백본 | 망 6:1:1 (회피) | 소음 계수 ×1.50 |
| 국방부 내부망 | 물리 1:1:6 (침투) | 소음 계수 ×0.78 |
| 군 지휘통제 | 암호 6:1:1 (해독) | 저항 상승 2.5 · 회복 0.2 |
| 기갑 전술망 | 균등 | 계층 7 · 손패 여유 2 |
| 지하 금고 | 물리·암호 | 능동대응 1단계부터 · 요구치 상승 45% |
| 암호화폐 거래소 | 암호·망 | 여유 이월 0.10 |

⚠️ **원형은 계층 유형 분포(`layerMix`)로 갈라야 한다.**
저항·손패·능동대응만 바꾸면 플레이 방식만 달라지고 **덱 선택은 안 바뀐다.**
초판에서 6종 중 4종이 글자 그대로 같은 최적 덱을 뽑았다.

원형별 요구치 배율은 **최강 덱이 약 65%** 가 되도록 이분탐색으로 정렬했다.
난이도가 다르면 플레이어는 항상 쉬운 표적만 고른다.

### 원형 추가 절차
1. `assets/balance.json` 의 `targets` 에 추가 (`layerMix` 필수)
2. `assets/l10n/{ko,en}.json` 에 `target.<id>.{name,line,desc}` 추가
3. `node sim/analysis/buildcheck.mjs` — 전용 덱이 1위이고 홈 어드밴티지 8%p 이상인지
4. `node sim/runAll.mjs` — 감사 통과 확인

## 8. 콘텐츠 확장 시 규칙

1. 새 카드는 `makeTool()` 로 예산에서 파생시킨다. **손으로 수치를 쓰지 않는다.**
2. 새 효과는 **덧셈 보너스가 아니라 규칙의 예외**여야 한다.
3. 효과는 **그 효과가 작동할 수 있는 조건**에서 잰다 —
   적응(morph)은 균형형에서 아무 일도 안 하고, 은폐는 소음이 낮으면 지울 게 없다.
4. **"그것만 8장" 덱으로 재지 않는다.** 난이도에 따라 천장이나 바닥에 붙어 무의미하다.
5. 소음 가격은 **덱 단위**로 검증한다.
