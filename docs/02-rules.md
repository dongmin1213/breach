# 02 · 룰 명세

수치의 단일 원본은 [`assets/balance.json`](../assets/balance.json) 이다.
이 문서의 숫자가 그것과 다르면 **JSON 이 맞다** — 정적 무결성 검사가 둘의 일치를 강제한다.

---

## 1. 이중 축

```
ACCESS  침투도   계층별 요구치를 넘어야 다음 계층으로
TRACE   탐지도   0 → 100. 100 도달 즉시 실패. 계층을 넘어도 초기화되지 않음
```

TRACE 가 계층마다 초기화되지 않는 것이 이 게임의 척추다.
초기화하면 각 계층이 독립 퍼즐이 되어 **런 단위 자원 관리가 사라진다.**

## 2. 한 계층의 판정

```
접근점수 = (주스탯 × 0.65 + 나머지 두 스탯 평균 × 0.35)
           × 효과배수 × 저항감소 × 권한배수 × 경계보너스
접근     = (접근점수 + 장비버프) × 계층강도

미달분   = max(0, 요구치 − 접근)
초과분   = max(0, 접근 − 요구치)

흡수분   = min(여유, 미달분)              ← 여유가 미달을 먼저 막는다
여유    += 초과분 × 0.70      (상한 60)
순미달   = 미달분 − 흡수분

소음     = 툴소음 × 6.0 × 효과배수 × 계층TRACE계수 × (1 + 경계단계 × 0.25)
ΔTRACE   = 소음 + 순미달 × 0.95 − 소거효과 + 우회비용
```

**부스탯 가중 0.35 는 협상 불가다.** 이 항이 없으면 극단 특화 카드가 수학적으로
항상 이기고 균형형이 전멸한다 (전작에서 확인).

## 3. 여유 (SLACK)

초과 달성분은 여유로 적립되어 뒤 계층의 미달을 흡수한다.

이게 없으면 최적해가 **"최소 소음으로 간신히 넘기기" 하나로 붕괴**한다.
없앴을 때 측정: 시끄러운 전략 19.0% vs 조용한 전략 50.9%, 레버리지 0인 계층 44%.

여유가 있으면 "쉬운 계층에서 크게 뚫어두고 어려운 계층을 조용히 넘긴다"가 성립한다.

## 4. 계층

| 유형 | 주스탯 | 요구치 | 강도 | TRACE 계수 | 성격 |
|---|---|---|---|---|---|
| **CIPHER** 암호 | DEC 해독 | 62.3 ~ 78.4 | 1.00~1.30 | 1.0 | 표준 |
| **NETWORK** 망 | EVA 회피 | 51.3 ~ 67.6 | 1.00~1.20 | **1.4** | 쉽지만 시끄럽다 |
| **PHYSICAL** 물리 | INF 침투 | 73.1 ~ 91.9 | 1.10~1.40 | **0.7** | 어렵지만 조용하다 |
| **CORE** 코어 | 계층 분포를 따름 | 84.1 ~ 105.5 | 1.60~2.00 | 1.2 | 최종. 표적당 1개 |
| **RECON** 정찰 | — | — | — | — | 툴 미제출, 장비 획득 |

NETWORK 와 PHYSICAL 의 요구치·TRACE 계수를 **반대 방향**으로 준 것이
"어디에 시끄러운 툴을 쓸 것인가"라는 배분 문제를 만든다.

## 5. 런 구조

```
카드 풀 30종 → 덱 12장 (플레이어가 구성)
채점 계층 5~7개 + 정찰 계층 2개
손패 = 채점 계층 수 + 4 (덱에서 뽑음, 리필 없음)
마지막은 반드시 CORE
```

**덱(12) > 손패(≈10) > 실제 사용(≈6).** 이 세 겹이 덱빌딩을 만든다.
근거는 [04-balance §손패](04-balance.md) 참조.

## 6. 적응형 방어 — 세 겹

### 저항 (RESIST) · 즉각 · 유형별
```
같은 유형을 낼 때마다   +1.0  (상한 3)
다른 유형을 낼 때       −0.5
접근점수 감소율/1저항    정공 13%  우회 7%  강습 18%
```
강습의 페널티가 가장 큰 이유: 한 방이 크므로 반복 페널티도 커야 "강습 몰빵"이 안 된다.

### 경계 (ALERT) · 누적 · 런 전체
```
TRACE 30 / 55 / 80 을 넘을 때마다 1단계 상승 (최대 3)
단계당 소음 발생량 +25%
```
늦게 갈수록 같은 행동이 더 비싸진다. 긴장 곡선의 실체다.

### 능동 대응 (COUNTER) · 경계 2단계부터

| 대응 | 효과 |
|---|---|
| 툴 봉인 | 손패에서 이번 계층 최적 툴 1장 제거 |
| 권한 초기화 | 권한 게이지를 0 으로 |
| 요구치 상승 | 이번 계층 요구치 +30% |
| 추적 가속 | TRACE +10 |

**모든 능동 대응은 정확히 한 채점 계층 앞서 예고된다. 타협 불가.**
예고 없는 대응은 플레이어가 배울 수 없는 패배를 만든다.

구현 주의 두 가지:
- **"예고"와 "발동 중"은 별도 필드**여야 한다. 한 필드로 합치면 진입 시 초기화 코드가
  발동 전에 지워버려 `요구치 상승`이 영구 사문화된다.
- **정찰 계층은 예고를 소비하지 않고 통과시킨다.** 안 그러면 정찰이 예고를 삼켜
  대비 기회가 0 인 케이스가 생긴다.
- 예고했는데 조건이 안 맞으면 **불발(FIZZLE)도 로깅**한다. 조용히 사라지면 인과가 끊긴다.

대응 선택은 **순환하되 지금 무해한 것은 건너뛴다.** 고정 순환만 쓰면 효과 없는 대응이
자주 나오고(권한 초기화 평균 손해 5점), "가장 아픈 것"을 고르게 하면 척도가 달라
한 종류로 쏠린다(툴 봉인 93%). 유효성은 **발동 시점** 기준으로 판단한다.

## 7. 권한 (PRIV)

```
축적형 툴   권한 +1 ~ +2 (상한 6)
소비형 툴   접근점수 × (1 + 권한 × 0.35), 사용 후 권한 0
```

여러 턴을 투자해 한 방을 만드는 라인. **이 게임에서 유일하게 성립하는 시너지 축이다.**

## 8. 장비 (정찰 계층 보상)

| 장비 | 효과 |
|---|---|
| 증폭기 | 다음 계층 접근 +22 |
| 소거기 | TRACE −14 (즉시) |
| 위장막 | 다음 계층 소음 0 |
| 분석기 | 예고된 능동 대응 무효화 |

동시 2개까지. **런이 끝나면 소멸하므로 아끼는 것 자체가 손해다.**

## 9. 점수

```
점수 = 500 + (100 − 최종TRACE) × 5 + 남은 툴 × 30 + 남은 여유 × 0.35
실패 = 0
```

조용히 뚫을수록, 툴을 아낄수록, 여유를 남길수록 높다.

## 10. 결정론

전투에 난수가 없다. 같은 시드면 표적·손패·전개가 완전히 같다.
이 속성 위에 **데일리 모드**와 **서버 검증**이 서 있다.
PRNG 는 mulberry32 고정이며 `Math.random`·시각 의존은 전면 금지다.
