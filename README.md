# BREACH

> **같은 표적을, 누가 더 영리하게, 더 조용히 뚫는가.**

싱글플레이 유료 카드 로그라이크. 세로 모바일. 가챠 없음.

당신은 해커다. 여러 겹으로 보호된 시스템을 계층 하나씩 뚫고 코어까지 들어간다.
계층마다 **필요 침투도**가 있고, 도구를 쓸 때마다 **탐지도**가 오른다. 탐지도 100이면 잡힌다.

센 도구일수록 시끄럽다. 조용한 도구는 약해서 필요치를 못 넘기고, **못 넘긴 만큼도 탐지도가 된다.**
양쪽 다 대가가 있어서, 어느 계층에 어느 도구를 쓸지가 전부다.

---

## 시작하기

```bash
flutter pub get
flutter run -d chrome        # 웹
flutter run                  # 연결된 기기
```

### 검증

```bash
tools/verify.sh              # 전 구간 (아래를 순서대로)
node sim/runAll.mjs          # 밸런스 감사 221개
dart test                    # Dart 엔진 18개 (골든 400런 포함)
dart test -p chrome test/prng_web_test.dart   # 웹 정수 의미론
```

**밸런스나 엔진을 건드렸으면 `tools/verify.sh` 를 통과시킬 것.**

## 구조

```
assets/       ★ 수치·텍스트 단일 원본 — 앱과 시뮬레이터가 같이 읽는다
  balance.json      수치 (영문 id + 숫자만)
  l10n/             한/영 문자열
lib/          Flutter 앱 (app · shared · features)
sim/          JS 밸런스 검증 하니스 — **룰의 기준 구현**
test/         Dart 테스트 + golden.json (포팅 정답지)
docs/         설계 문서
tools/        verify.sh
```

**카드를 추가하려면** `assets/balance.json` 에 한 줄 + `assets/l10n/{ko,en}.json` 에 이름.
코드는 안 건드린다.

## 이 프로젝트가 특이한 점

밸런스를 감으로 정하지 않는다. **221개 검사가 매 변경을 검증**하고,
수치를 바꾸면 시뮬레이터가 그 값을 검증한 뒤 앱이 그 값으로 돈다 (`assets/balance.json` 한 벌).

전작(카트 레이싱 카드배틀)은 400개 관점 감사를 통과하고도 **구조 결함**으로 폐기됐다.
그때 배운 것과 이번에 반복한 실수가 [06 발견](docs/06-findings.md) 에 전부 적혀 있다.
